# Paper blueprint tooling

Tooling for the [complete browser blueprint](../../docs/roadmap/tasks/paper-browser-blueprint.md):
a minimal client for the local Paper Desktop MCP endpoint (`paper.py`), the
token-only component library (`lib.py`, `blocks.py`), the board inventory and
coverage matrix (`inventory.py`, `coverage.py`), one generator per wave
(`w*.py`, `index.py`) and the two gates:

```bash
python3 scripts/paper_blueprint/verify_tokens.py   # Paper tokens = code values
python3 scripts/paper_blueprint/check_coverage.py  # every board and row drawn
```

Both need Paper Desktop running with the "BBR — Browser Shell" file open.
`tint.json` is generated by `tint.py` from `space_tint.rs`; `token*.json` are
snapshots of the Paper token set read by `lib.py`.
